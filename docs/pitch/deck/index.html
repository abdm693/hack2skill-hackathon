EngineeringNaqsha نقشہ

Built for real quotas, tested by agents

Every step of a run has a guardrail, so a long agent job survives quota errors, bad output and closed tabs. Then agents tested the live app until it held.

Backoff and fallbacks

429s and 5xx errors retry with backoff and jitter, 4 s to 60 s. Concept images fall back to Nano Banana 2.1, then 3 Pro Image.

Degenerate-decoding watch

A runaway tail such as 35.0000000… aborts and retries the attempt. Prompts cap numbers at 2 decimals.

21 banned patterns

Network, eval, storage, timers and globals are screened out of generated code before it runs.

Self-healing sections

A section that throws is rewritten on its own by Argon. If an ADK run fails, a single-shot reviser takes over.

Engine invariants

Railings at every drop, door keep-outs, the roof door at the landing, and nothing in a setback beyond the chajja allowance.

Detached runs

A design keeps going when the tab closes. When it comes back, every event replays, then the run goes live.

Guardrails: api/app/gemini.py, llm.py, runs.py, web/src/engine · Testing: docs/review/*-triage.md, api/tests (pytest)

"Here is what keeps a six-minute agent run reliable. The global endpoint's shared quota returns 429s under load, so every call retries with backoff and jitter, and concept images fall back to a second and a third image model. Constrained decoding sometimes loops on digits, so we watch the stream and cut it off. Generated code is screened before it runs, and a broken section repairs itself. The engine guarantees railings, door clearances and the roof door whatever Argon writes, and the whole run is detached from the browser. Then we tested it like a product: eight tester agents per round used the live app as families, architects and builders would, over three rounds and a final check. That produced about two hundred fixes, and the API has a hundred and twenty-three tests. The final check confirmed every item on our must-fix list on the deployed code."

Sources: api/app/gemini.py (RETRY), api/app/config.py (MODEL_IMAGE_FALLBACKS), api/app/llm.py (degenerate), web/src/engine/index.ts (BANNED), api/app/agents/architect.py (repair_section), api/app/compliance/planning.py and lda.py (invariants, check_asbuilt), api/app/main.py (revise fallback), api/app/runs.py.
