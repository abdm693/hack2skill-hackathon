Source: LDA Building & Zoning Regulations 2019, consolidated text of 9 Feb 2026, Appendix C

"Picture a family in Johar Town with a 10-marla plot. Their house begins as a pencil sketch and a contractor's best guess. The rules for that plot are precise: ten feet open at the front, seven at the rear, five on one side, seventy percent coverage, forty-five feet, and now three storeys, not four. That changed in LDA's 2026 text. A registered architect must stamp the plan. Mistakes are expensive: every resubmission pays the scrutiny fee again, about thirty-eight thousand rupees for a house like ours, and a porch pushed four feet into the front open space costs fifteen to thirty thousand in penalties, if LDA compounds it at all."

Arithmetic: Rs 15 × 2,565 sq ft (total covered area of the 10-marla sample, live API) = Rs 38,475. Porch: 4 ft × 15 ft = 60 sq ft; Rs 250/sq ft (porch projection over the limit) to Rs 500/sq ft (ground-floor open-space violation), both Appendix C [v2026].

Livable-home rulesIn the 18 Oct build
  • Bedrooms open only to a corridor, lounge, balcony or their own bath.
  • A stair reaches every floor, roof included.
  • A railing at every drop, enforced by the engine.
  • Doors kept clear of furniture, with a 3′ path.

We audited three houses (two by Argon, one hand-made). All three had stair-safety defects. LDA doesn't define guards, so we apply IBC 2021.

One service, one URL. No CORS, and a deploy is one gcloud run deploy --source .

google-genai 2.31 · google-adk 2.12 · Cloud Run, 3,600 s request timeout

"The architecture is deliberately simple. One Cloud Run service serves the API and the app. Gemini runs through Vertex AI on the global endpoint, the only place the newest models are served. Firestore holds projects, versions and comments; Cloud Storage holds images. The interesting part is the two loops into the deterministic engine: Argon plans against it, and the ADK reviser dry-runs every change against it. We match the model to the job: Flash for quick turns, Flash Image for four concepts at once, and Argon for anything that has to reason about limits or write long, correct code."

Generated code runs in the user's browser after a static screen for 21 banned patterns; a sandboxed iframe is on the roadmap. Identity Platform accounts are in the 18 Oct build.

EngineeringNaqsha نقشہ

Built for real models on real quotas

Every step of a design run has a guardrail, so a long agent job survives quota errors, bad output and closed tabs.

Backoff on quota errors

429s and 5xx errors retry with exponential backoff and jitter: 6 attempts, from 4 s up to 60 s. google-genai and ADK share the policy.

Degenerate-decoding watch

A runaway tail such as 35.0000000… aborts and retries the attempt. Prompts cap numbers at 2 decimals.

21 banned patterns

Network, eval, storage, timers and globals are screened out of generated code before it runs.

Self-healing sections

A section that throws is rewritten on its own by Argon. If code is missing, a default design is built from the plan.

Nothing in a setback

No part of the 3D model may reach into an open space beyond the chajja (sunshade) allowance: 3 ft, or 1.5 ft where the space is under 10 ft.

A fallback reviser

If the ADK run fails, a single-shot reviser takes over. ADK saves nothing until it finishes.

Each guardrail is in the public repo: retry policy, stream guard, code screen, repair, as-built check, fallback

"Here is what keeps a seven-minute agent run reliable. The global endpoint's shared quota returns 429s under load, so every call retries with backoff and jitter, in both google-genai and ADK. Constrained decoding sometimes loops on digits, so we watch the stream and cut it off. Generated code is screened before it runs, and a broken section repairs itself. The finished model is checked again: nothing may project into a setback. The ADK agent has a fallback. And the whole run is detached from the browser. None of this shows in the demo, which is the point."

Sources: api/app/gemini.py (RETRY), api/app/llm.py (degenerate), web/src/engine/index.ts (BANNED, defaultDesign), api/app/agents/architect.py (repair_section), api/app/compliance/lda.py (check_asbuilt), api/app/main.py (revise fallback), api/app/runs.py.

How it scales
Cloud Run, as deployed

Autoscales to 5 instances today, each 2 vCPU and 2 GiB with 40 concurrent requests, CPU always on. The cap is one flag.

A shared Gemini quota

Every call to the global endpoint backs off on 429s, so a burst queues instead of failing.

Long jobs

Today: an in-memory event log per instance, held by session affinity. Next: the log in Firestore with Cloud Tasks, so any instance can resume.

Cost follows intent

Samples open with no model calls. Briefs and concepts use Flash models; Argon runs only on a full design.

New cities are data
