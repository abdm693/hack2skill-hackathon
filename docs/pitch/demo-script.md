# Demo video script (under 3 min)

Kept consistent with the deck (`docs/pitch/deck/`, facts in `docs/pitch/deck/facts.json`) and the live app, revision `naqsha-00009` (17 Oct 2026). No "half rejected" or "approval-ready" claims: say "LDA-checked" or "pre-check". Numbers used: 45–94 s for four concepts, about 5–6 min for a 10 marla design, about 70 s for a revision, 37/37 LDA and 10/10 livable on the 10 marla sample.

**Setup.**
- Screen-record at 1440×900 in a fresh guest workspace on the live URL, in Chrome.
- Type the brief live, then cut to the **10 marla sample** (Samples → 10 marla modern home) for concepts, plan, house and versions, so nobody waits for the image models or the 5–6 min design run on camera. Say so once ("here is the same brief, already designed").
- The compliance panel's first line reads "Approval-ready". Don't zoom on it, and don't read it out.
- For the sharing beat, have a second browser profile (or a private window) ready to open the client link. Turn the link off and delete any test comments afterwards.
